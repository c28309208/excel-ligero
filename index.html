Conectar datos desde una URL

Trae un CSV o un JSON (lista de listas u objetos). El sitio debe permitir CORS; si no, descarga el archivo y usa Abrir.

Atajos y funciones

Atajos

  • Flechas: mover · Shift+Flechas: seleccionar
  • Enter: editar / confirmar · F2: editar
  • Supr: borrar · Ctrl+C / V: copiar y pegar
  • Ctrl+Z / Y: deshacer y rehacer
  • Ctrl+B / I / U: negrita, cursiva, subrayado

Funciones

SUMA, PROMEDIO, MIN, MAX, CONTAR, CONTARA, SI, SI.ERROR, Y, O, NO, REDONDEAR, ENTERO, RESIDUO, POTENCIA, RAIZ, CONCATENAR, LARGO, IZQUIERDA, DERECHA, EXTRAE, MAYUSC, MINUSC, ESPACIOS, ENCONTRAR, SUSTITUIR, VALOR, TEXTO, HOY, AHORA, AÑO, MES, DIA, FECHA, BUSCARV, INDICE, COINCIDIR, CONTAR.SI, SUMAR.SI, PROMEDIO.SI, MEDIANA, MAYOR, MENOR, SUMAPRODUCTO.

También en inglés: SUM, AVERAGE, IF, VLOOKUP, COUNTIF…
